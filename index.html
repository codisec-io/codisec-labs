Instale a CLI

Único pré-requisito: Docker Desktop instalado e aberto.

Linux curl -sSL labs.codisec.com.br/install.sh | bash
macOS curl -sSL labs.codisec.com.br/install.sh | bash
Windows (PowerShell) iwr labs.codisec.com.br/install.ps1 -useb | iex

Escolha um lab

Veja o catálogo no site, filtre por categoria e nível.

  codisec lab list

Rode localmente

O ambiente sobe no seu próprio Docker — nada passa pelo nosso servidor.

  codisec lab start appsec-idor-api
